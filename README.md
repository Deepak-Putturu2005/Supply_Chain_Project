Supply Chain Analytics Project.

📌 Project Overview

This project is a comprehensive Supply Chain Data Analytics project developed to analyze business performance using data cleaning, SQL analysis, KPI calculation, and interactive data visualization.

The project transforms raw supply-chain data into meaningful business insights by analyzing "revenue, profitability, order performance, delivery performance, customer performance, regional performance, and inventory-related information".

Four major analytics tools were used throughout the project:

- Microsoft Excel
- MySQL
- Tableau
- Microsoft Power BI

The final outcome is a set of KPI analyses and interactive dashboards that provide an executive-level view of supply-chain performance.

📂 Dataset

The project uses a supply-chain dataset containing information related to "orders, customers, products, suppliers, warehouses, inventory, revenue, delivery and operational performance".

The data was organized into fact and dimension tables for analysis and reporting.

Major Data Areas

- Order information
- Customer information
- Product information
- Supplier information
- Warehouse information
- Inventory information
- Revenue and cost information
- Shipping and delivery information
- Order dates and delivery dates
- Customer regions and countries

The dataset was first examined and prepared before performing KPI calculations and visualization.

🛠️ Tools Used

1. Microsoft Excel

Excel was used for initial data exploration, cleaning, calculations and dashboard development.

Main Activities

- Data inspection
- Data cleaning
- Data validation
- KPI calculations
- Pivot-based analysis
- Charts and dashboard creation
- Initial performance analysis

Excel helped establish the basic structure of the analysis before developing the advanced dashboards.

2. MySQL

MySQL was used for structured data analysis and KPI calculations.

SQL queries were created to extract, filter, aggregate and analyze the supply-chain data.

SQL Operations Used

- SELECT
- WHERE
- GROUP BY
- ORDER BY
- JOIN
- SUM()
- AVG()
- COUNT()
- Conditional calculations
- KPI calculations

Major Analysis

- Total Revenue
- Revenue by Region
- Monthly Revenue
- Order Performance
- Delivery Performance
- Delayed Orders
- Customer Analysis
- KPI calculations

MySQL provided the analytical foundation for understanding the dataset and generating measurable business metrics.

3. Tableau

Tableau was used to create interactive visualizations and dashboards.

Major Visualizations

- Monthly Revenue Trend
- Revenue Share by Region
- Revenue by Customer Country
- Geographical Revenue Analysis
- Delivery and Order Performance

The Tableau dashboard provides an interactive view of geographical and time-based supply-chain performance.

4. Microsoft Power BI

The dashboard combines KPI cards, charts, maps and slicers into a single interactive reporting interface.

Main KPI Cards

- Total Revenue
- Gross Margin %

- Fill Rate %
- Perfect Order Rate %

Main Dashboard Visuals

- Monthly Revenue Trend
- Revenue Share by Region
- Revenue by Customer Country
- Customer Region Slicer
- Order Date Slicer
- Revenue Slicer
- Geographical Analysis

The Power BI dashboard provides an executive-level summary of supply-chain performance and allows users to interactively filter the analysis.

📊 Key Performance Indicators

The project analyzes 20 Key Performance Indicators (KPIs) covering revenue, profitability, order, delivery, customer and operational performance.

Some of the major KPIs include:

| KPI | Purpose |

| Total Revenue | Measures overall revenue generated |
| Gross Margin % | Measures profitability |
| On-Time Delivery % | Measures delivery performance |
| Fill Rate % | Measures order fulfillment |
| Perfect Order Rate % | Measures overall order quality |
| Order Cycle Time | Measures order completion time |
| Average Order Quantity | Measures average quantity per order |
| Average Processing Time | Measures order processing efficiency |
| Average Delay | Measures delivery delays |
| Delayed Orders | Measures the number of delayed orders |
| COGS | Measures product-related costs |
| Gross Profit | Measures profit after COGS |
| Shipping Cost | Measures transportation/shipping expenses |
| Revenue per Order | Measures average revenue per order |
| Revenue Share % | Measures contribution by region/category |
| Transportation Time | Measures delivery transportation duration |
| Order Quantity | Measures total quantity ordered |
| Processing Days | Measures order processing duration |
| Delivery Performance | Evaluates delivery efficiency |
| Regional/Customer Revenue | Measures geographical and customer contribution |
